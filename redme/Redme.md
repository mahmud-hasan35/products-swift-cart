১::
 null এবং undefined এর পার্থক্য
JavaScript এ undefined মানে হলো কোনো ভ্যারিয়েবল ডিক্লেয়ার করা হয়েছে কিন্তু তাকে এখনো কোনো মান দেওয়া হয়নি। তখন JavaScript নিজে থেকেই তাকে undefined ধরে।
অন্যদিকে null মানে হলো ইচ্ছা করে খালি রাখা। অর্থাৎ আমরা নিজেরাই বুঝাতে চাই যে এখানে কোনো মান নেই।



২::
  map() ফাংশনের ব্যবহার এবং forEach() পার্থক্য
map() ফাংশন একটি অ্যারের প্রতিটি উপাদানের উপর কাজ করে এবং কাজ শেষে একটি নতুন অ্যারে রিটার্ন করে। সাধারণত যখন আমরা কোনো অ্যারের ডাটা পরিবর্তন করে নতুন অ্যারে বানাতে চাই তখন map() ব্যবহার করি।
অন্যদিকে forEach() শুধু প্রতিটি উপাদানের উপর লুপ চালায়, কিন্তু এটি কোনো নতুন অ্যারে রিটার্ন করে না।







৩::
 == এবং === এর পার্থক্য
== শুধু মান (value) তুলনা করে। প্রয়োজন হলে এটি টাইপ পরিবর্তন করে নেয়।
কিন্তু === মান এবং টাইপ দুইটাই একসাথে তুলনা করে।
যেমন,
5 == "5" হলে true হবে,
কিন্তু 5 === "5" হলে false হবে কারণ একটার টাইপ নাম্বার আরেকটা স্ট্রিং।







৪::
  API ডাটা আনার ক্ষেত্রে async/await এর গুরুত্ব
async/await ব্যবহার করলে API থেকে ডাটা আনার কোড অনেক সহজ ও পরিষ্কার হয়। এটি Promise হ্যান্ডেল করার একটি আধুনিক পদ্ধতি।
আগে .then() ব্যবহার করতে হতো, কিন্তু async/await ব্যবহার করলে কোড পড়তে সহজ হয় এবং ভুল (error) হ্যান্ডেল করাও সহজ হয়।
এ কারণে আধুনিক JavaScript এ async/await খুব গুরুত্বপূর্ণ।






৫::
 Scope এর ধারণা (Global, Function, Block)
Scope মানে হলো একটি ভ্যারিয়েবল কোথায় ব্যবহার করা যাবে।
Global Scope:
যদি কোনো ভ্যারিয়েবল ফাংশনের বাইরে লেখা হয়, তাহলে সেটি পুরো প্রোগ্রামে ব্যবহার করা যায়।

Function Scope:
যদি কোনো ভ্যারিয়েবল ফাংশনের ভিতরে লেখা হয়, তাহলে সেটি শুধু ওই ফাংশনের মধ্যেই ব্যবহার করা যাবে।

Block Scope:
যদি let বা const দিয়ে কোনো ভ্যারিয়েবল thirt {}  এর ভিতরে লেখা হয়, তাহলে সেটি শুধু ওই ব্লকের ভিতরেই কাজ করবে।
